# 未知 B：源事务与旧执行者隔离探针

本轮 **evidence_incomplete**。实验使用独占的真实 MySQL source/state 实例；仅增加测试设施，没有修改 UNKNOWN grant、Journal 状态转换或自动恢复协议。

| 窗口 | 实测结果 | 边界 |
|---|---|---|
| 提交 | 在 InnoDB 观察到与连接 ID 匹配的未决事务，其他会话看不到控制行；提交、连接及事务消失后行可见，观察器返回 CONFIRMED | 控制表事务/观察器组件样本，没有 Reader、Journal 或 Sink |
| 回滚 | 同样固定真实事务，回滚及服务端释放后控制行不存在，观察器返回 CONFIRMED | 不能据此证明原 B 可重新写入或任务已经恢复 |
| 迟提交 | 未决事务存在时 `beforeStart` 因旧会话或事务未释放而拒绝；迟提交、实际连接/事务消失后行可见，观察器返回 CONFIRMED | 观察器组件样本，不证明旧 JVM 已隔离 |
| 旧 JVM 迟到重连 | 独立旧 JVM 启动后在连接前等待；观察器记录 CONFIRMED 后，释放旧 JVM，它重新连接并提交控制行；观察器随后返回 UNKNOWN | 反例说明某时刻数据库空闲不是未来隔离证明；没有恢复许可、Journal 或 Sink 验收 |

首轮三个样本在 JDBC `close()` 返回后立即采样，观察器仍发现未释放资源，均失败。后续先等待服务端会话和事务消失，再执行检查；另一次将 InnoDB 事务与同一连接 ID 固定后重跑，最终三项通过。首轮失败和中间采样不足的结果均保留，不能把早期零事务采样写成已固定切点。

候选 4（事务样本）源码清单 SHA-256 和候选 5（旧 JVM 反例）清单见[脱敏证据包](evidence.zip)，共同生产源码 SHA-256 `ac6141e4299e175867b78f1d511b52f87d946881ba0af7f8ff07b835e258f609`；证据包 SHA-256 `d1f73d97ab4e5b657cf3bbd00b28cd44eaee45866070ae28e8494efe91e49c3d`。包内保留结构化样本、退出码、候选清单及脱敏结果摘要，不包含完整 JVM 日志、凭据或 binlog。

尚未完成旧 CDC owner 可靠隔离、隔离证明与资源观察的持久绑定、Journal 允许恢复的状态转换、UNKNOWN grant/配额原子回收及受控重启后的逐字段对账。现有 `SnapshotGuardian` 属于受管静态快照，尚不能直接作为共享 CDC owner 的隔离证明；不能只以 PID 或数据库暂时空闲放行。
