## 统一阅读口径

- **源码结论**：来自 `pekko-reference` 当前源码调用链。
- **实际实验**：来自真实 MySQL、Actor Journal、Sink 或集群运行。
- **保存材料复算**：重新读取既有材料，不等于重新运行。
- **未验证边界**：证据不足时保留未知，不把设计目标写成运行结果。

源码阅读基线为工作区 `cc09559`。历史 LOW/HIGH、ACK proof、资源释放和 GC 材料仍按各自冻结版本解释；五篇文章不会把不同版本的结果合并成一次验收。
