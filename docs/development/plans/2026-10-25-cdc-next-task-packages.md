## 划分原则

- 三类依赖分别标记：设计契约、代码依赖、实验环境依赖。能做设计/测试准备，不代表可以先实现尚未批准的协议。
- 不同 schema 或 server-id 不构成 binlog 隔离；共享源实例仍可能因事务元数据、DDL、purge 和 offset I/O 互相影响。
- 每个包有独占文件范围。消费者使用冻结契约，不由两个执行者同时修改公共模型或入口。
- 先定点复现和回归，生产代码稳定后再对一个候选版本跑完整矩阵。文档调整或互不相关的测试设施修改不触发无差别全量重跑；对应源码/测试摘要分别记录。
- 原始失败、旧持久化类型和 T/J/D 含义保留。不静默 latest、不改写 D、不重发 B 来掩盖起点变化；需要新协议的地方先给方案。
